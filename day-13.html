CSS Position Types

Important position properties used in CSS

RELATIVE
📦

Relative

The element remains in its normal position and can be moved using top, right, bottom and left.

ABSOLUTE
🎯

Absolute

The element is positioned relative to its nearest positioned parent.

FIXED
📌

Fixed

The element stays fixed relative to the browser window during scrolling.

STICKY
🔒

Sticky

The element behaves normally until it reaches its sticky position.
